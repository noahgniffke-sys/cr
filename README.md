# CR

A private desk for posting one video to every network you select.

## Open

Send this page. The steps are on it:

https://noahgniffke-sys.github.io/cr/

## One-time setup

1. Create a free account at [upload-post.com](https://upload-post.com) and copy the API key.
2. Paste the key into CR. The profile name can stay `friend`. Both stay in this browser.
3. On CR, choose Sign in on each network. That opens the network's own login, then brings you back. Instagram must be a Business or Creator account. Facebook must be a Page.

## Posting

Choose one video. The limit is 95 MB. Write the title.

Post to all sends the video to every network that is signed in. Post on one row sends it to that network only. Story on Instagram or Facebook posts it as a 24-hour story.

Schedule applies to whichever button you press. After the click succeeds, the tab can close.
